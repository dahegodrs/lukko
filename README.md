# 💰 Lukko

**Lukko** es una aplicación móvil multiplataforma desarrollada en Flutter que permite a los usuarios administrar de forma sencilla sus cuentas personales, ingresos y gastos. Con un enfoque visual, intuitivo y moderno, Lukko está diseñada para facilitar el control financiero incluso a quienes no tienen conocimientos contables.

## ✨ Características

- Registro y visualización de **cuentas** con cupo, red de pago y deuda.
- Administración de **movimientos financieros** (ingresos y gastos) categorizados.
- Impacto en tiempo real del saldo de la cuenta al agregar, editar o eliminar movimientos.
- Temas personalizados oscuros con una paleta moderna (verde, gris y tonos crema).
- Arquitectura basada en **Provider** para manejo eficiente del estado.
- Soporte para múltiples pantallas y navegación estructurada.

## 🚀 Instalación local

1. Clona el repositorio:

   ```bash
   git clone https://github.com/dahegodrs/lukko.git
   cd lukko

   ```

2. Instala dependencias:
   flutter pub get

3. Corre la aplicación en modo desarrollo:
   flutter run

4. (Opcional) Genera el APK:
   flutter build apk
   El archivo generado estará en:
   build/app/outputs/flutter-apk/app-release.apk

📦 APK de instalación
Puedes descargar la última versión APK desde la sección Releases o directamente desde este repositorio si está incluido en la carpeta release.
